DormLaundry - расписание стиралок общежития

Fullstack-приложение для бронирования стиральных и сушильных машин в общежитии.

Назначение приложения:
Приложение предназначено для студентов, проживающих в общежитии, для просмотра статуса стиральных и сушильных машин, а также бронирования удобного времени стирки. Цель - избавление от живых очередей и оптимизация времени студентов.

Основные пользовательские сценарии
1. Студент: Авторизация в системе.
2. Студент: Просмотр списка доступных машин и их текущего статуса.
3. Студент: Выбор машины и бронирование свободного часового слота в расписании.
4. Студент: Просмотр своих активных бронирований и их отмена.
5. Администратор: Изменение статуса машины (например, отметка "Не работает").

Необходимые экраны
Экран авторизации/регистрации - форма входа.
Главный экран (Список) - карточки машин с индикаторами (свободна/занята/сломана).
Экран расписания (Бронирование) - календарь/список слотов для конкретной машины.
Экран профиля (Мои записи) - список будущих стирок пользователя.

Архитектура Frontend (Feature-Sliced Design)
Фронтенд-часть приложения структурирована по принципам модульной методологии Feature-Sliced Design (FSD) в упрощенном виде:

`src/app/` - инициализация приложения, провайдеры контекста, глобальные стили и темы Material-UI.
`src/pages/` - полноэкранные страницы приложения, объединяющие фичи и сущности в готовые представления (`MachinesPage`, `SchedulePage`, `MyBookingsPage`, `LoginPage`).
`src/features/` - интерактивные пользовательские сценарии и действия (`filter-machines` — фильтрация каталога по типам и этажам, `book-slot` — форма бронирования интервала, `auth` — форма входа).
`src/entities/` - бизнес-сущности предметной области и их визуальное отображение (`machine` — карточка стиральной/сушильной машины `MachineCard`, `booking` — плашка бронирования `BookingItem`, `user` — данные студента).
`src/shared/` - переиспользуемые ресурсы без привязки к конкретной бизнес-логике (`ui` — общая навигация `Navbar`, модальные окна, кнопки; `types` — TypeScript-интерфейсы `LaundryMachine`, `Booking`, `User`; `api` — клиенты сетевых запросов).

Модель данных (PostgreSQL & SQLAlchemy)
В проекте спроектирована реляционная схема базы данных со связями «один-ко-многим» и каскадным удалением:

1. Таблица `users` (Студенты / Пользователи)
Хранит учетные данные пользователей сервиса.
`id` (Integer, Primary Key) - уникальный идентификатор пользователя.
`full_name` (String(100), NOT NULL) - ФИО студента.
`room_number` (String(20), NOT NULL) - номер комнаты в общежитии.
`telegram_id` (String(50), Unique, Nullable) - никнейм/ID в Telegram для уведомлений.
`created_at` (DateTime, NOT NULL) - дата и время регистрации.

2. Таблица `machines` (Оборудование прачечной)
Хранит парк техники (стиральные машины и сушилки).
`id` (Integer, Primary Key) - уникальный идентификатор оборудования.
`name` (String(50), NOT NULL) - наименование устройства (напр., «Стиральная машина 1», «Сушилка 2»).
`machine_type` (Enum: `washer`, `dryer`, NOT NULL) - тип оборудования (стиралка или сушилка).
`floor` (Integer, NOT NULL) - этаж размещения прачечной комнаты.
`status` (Enum: `available`, `in_use`, `maintenance`, NOT NULL) - статус готовности к работе.
`created_at` (DateTime, NOT NULL) - дата добавления оборудования.

3. Таблица `bookings` (Бронирования слотов)
Связующая таблица для фиксации слотов стирки/сушки.
`id` (Integer, Primary Key) - уникальный идентификатор бронирования.
`user_id` (Integer, Foreign Key -> `users.id` ON DELETE CASCADE, NOT NULL) - ссылка на студента.
`machine_id` (Integer, Foreign Key -> `machines.id` ON DELETE CASCADE, NOT NULL) - ссылка на забронированную машину.
`start_time` (DateTime, NOT NULL) - дата и время начала интервала.
`end_time` (DateTime, NOT NULL) - дата и время завершения интервала.
`status` (Enum: `active`, `completed`, `cancelled`, NOT NULL) - статус бронирования.
`created_at` (DateTime, NOT NULL) - дата и время создания записи.

Связи:
User -> Bookings: один-ко-многим (`relationship("Booking", back_populates="user")`).
LaundryMachine -> Bookings: один-ко-многим (`relationship("Booking", back_populates="machine")`).
